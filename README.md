AMF Task Manager

Description
AMF Task Manager is a web-based application designed to help users efficiently manage their tasks. It allows users to create, update, and delete tasks while keeping track of their status.
Features.

✅ User authentication (Login & Register)
✅ Create, edit, delete, and view tasks
✅ Task status management
✅ Responsive UI with Bootstrap
✅ Secure data storage with SQLite

Technologies Used
•	Backend: C#, .NET, ASP.NET Core MVC
•	Frontend: HTML, CSS, Bootstrap
•	Database: SQLite
•	Version Control: Git & GitHub

Installation & Setup
1.	Clone the repository:
    git clone https://github.com/MadushaNadiranga/TaskManager

2.	Open the project in Visual Studio

3.	Configure the database connection in appsettings.json

4.	Apply migrations and update the database:
    dotnet ef database update

6.	Run the project:
    dotnet run
